# Behavioral Interoperability Testing Ontology (BITO)

**Version:** 1.0.0  
**Status:** Review version

**License:** CC BY 4.0

## Overview

The Behavioral Interoperability Testing Ontology (BITO) provides a lightweight semantic model for ontology-driven behavioral interoperability testing. It represents the link between expected scenario behavior, observed execution evidence, behavioral constraints, validation results, and verdicts. It is a reusable behavioral layer that can complement domain ontologies and support validation of runtime behavior.


## Repository contents

```text
ontology/       Ontology files in TTL and RDF/XML
docs/           WIDOCO-generated documentation
queries/        SPARQL and DL competency-question queries
validation/     HermiT, OOPS, and CQ validation evidence
```
