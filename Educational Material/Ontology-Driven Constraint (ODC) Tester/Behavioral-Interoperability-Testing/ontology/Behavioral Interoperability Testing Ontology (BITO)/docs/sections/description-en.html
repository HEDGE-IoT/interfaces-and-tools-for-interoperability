Behavioral Interoperability Testing Ontology (BITO): Description back to ToC

The Behavioral Interoperability Testing Ontology (BITO) defines the core semantic elements required to represent and assess behavior in ontology-driven behavioral testing. It models the considered use case and scenario, the implementation under test, the interacting actor or system, the triggering interaction, expected state transitions, behavioral constraints, observed execution, trace evidence, validation results, and validation verdicts. The ontology is not intended to replace domain ontologies. Instead, it acts as an additional behavioral layer on top of reused vocabularies. Concepts from SAREF and SAREF4ENER are reused where they are suitable for representing devices, states, power sequences, slots, units, and related energy-domain structures. PROV-O is reused for actor, activity, and evidence-related modelling where appropriate, and OWL-Time is reused for temporal modelling support. bito introduces additional behavioral concepts when the reused vocabularies do not sufficiently represent the required validation semantics. The ontology supports the representation of both expected behavior and observed execution evidence. Expected behavior is represented through scenarios, triggering interactions, expected state transitions, applicable behavioral constraints, and expected operational outcomes. Observed behavior is represented through observed events, observed state changes, timestamps, trace evidence, validation results, and verdicts. This structure makes it possible to connect scenario-level behavioral expectations with execution-side evidence. The current version includes representative instances for three Flexible Start behavioral scenarios. These instances are included as validation examples to demonstrate how the ontology can support competency-question checking, trace-evidence representation, and behavioral assessment. They should be understood as examples of the modelling approach, not as a limitation of the ontology scope.
