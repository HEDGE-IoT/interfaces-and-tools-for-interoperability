Abstract

The Behavioral Interoperability Testing Ontology (BITO) provides a semantic representation basis for ontology-driven behavioral interoperability testing. It supports the modelling of expected scenario behavior, behavioral constraints, observed execution evidence, trace evidence, validation results, and verdicts. The ontology is intended to make behavioral assessment explicit and reusable by connecting what is expected from an implementation under test with what is observed during execution. BITO is designed as a lightweight behavioral layer that complements reused domain ontologies. It reuses existing concepts where their semantics are aligned with the intended behavioral modelling purpose, and introduces additional concepts only where required to represent scenario behavior, constraints, observed executions, and trace-based assessment. The current version also includes representative validation instances used to demonstrate the ontology over Flexible Start behavioral scenarios.
